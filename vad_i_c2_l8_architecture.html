1. Architecture Overview

VAD_I_C2_L8 is a lightweight 1D convolutional neural network designed for Voice Activity Detection (VAD) at extremely low computational cost (≈ 2 MMAC/s). The network operates directly on 16 kHz raw audio samples and outputs frame-level decisions at 125 Hz (one decision every 8 ms).

The architecture follows an encoder–core–decoder pattern with three functional sections:

Forward Transform
Encoder (3 layers)
Downsamples input by 8× (stride-2 per layer)
Channels: 1 → 2 → 4 → 8
Core
Processing (7 layers)
4 layers stride-2 + 3 layers stride-1
Residual connections, 8 channels
Inverse Transform
Decoder (2 layers)
Maps features to output
Channels: 8 → 4 → 2
Building block — ResCbr1dGen: Each layer is a Residual Conv-BatchNorm-ReLU 1D block. In the core section, layers include a skip (residual) connection that adds the input to the output, aiding gradient flow and enabling the network to learn identity mappings. The forward_transform and inverse_transform layers do not use residual connections because the channel count changes between input and output.

Decimation structure: The network achieves 128× downsampling through 7 stride-2 layers (27 = 128). After layer 9 the signal reaches the final rate of 125 Hz, and layers 10–16 operate at stride 1 (no further downsampling). The output length decreases from 347 to 188 frames due to the valid-convolution boundary effects (no padding to preserve length).

Design philosophy: This network was designed to operate within a strict 10 MMAC/s computational budget, achieving only 2.03 MMAC/s — about 20% of the budget. The extremely small parameter count (5,510) and narrow channel widths (max 8 channels) make this model suitable for deployment on resource-constrained embedded processors and DSPs where memory and compute are severely limited.
