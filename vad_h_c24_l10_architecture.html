1. Architecture Overview

VAD_H_C24_L10 is a 1D convolutional neural network for Voice Activity Detection (VAD) with a computational budget of ≈ 23 MMAC/s. The network operates directly on 16 kHz raw audio samples and outputs frame-level decisions at 250 Hz (one decision every 4 ms).

A distinguishing feature of this architecture is its mixed alignment strategy: the first three encoder layers use center alignment (symmetric padding), while all remaining layers use right alignment (causal padding). This produces a near-causal network with minimal right crop (only 84 samples = 5.25 ms).

The architecture follows an encoder–core–decoder pattern with three functional sections:

Building block — ResCbr1dGen: Each layer is a Residual Conv-BatchNorm-ReLU 1D block. In the core section, layers include a skip (residual) connection that adds the input to the output, aiding gradient flow and enabling the network to learn identity mappings. The forward_transform and inverse_transform layers do not use residual connections because the channel count changes between input and output.
Mixed alignment: Layers 1–3 use center alignment CENTER, which distributes padding symmetrically and introduces a small right crop (84 samples total). From layer 4 onward, all layers use right alignment RIGHT (fully causal), contributing zero additional right crop. This hybrid strategy achieves a good trade-off between low latency and filter symmetry in early feature extraction.

Symmetric kernel placement: Layer 1 and layer 16 both use a large kernel of 128. Layer 1 operates at the input rate (16 kHz) for initial feature extraction, while layer 16 operates at the final decimated rate (250 Hz) for output smoothing. This “bookend” pattern is characteristic of encoder-decoder audio architectures.

Decimation structure: The network achieves 64× downsampling through 6 stride-2 layers (26 = 64). After layer 6 the signal reaches the final rate of 250 Hz, and layers 7–16 operate at stride 1 (no further downsampling). Near-causal architecture: Due to the mixed alignment strategy, this network is not fully causal — the first three center-aligned layers introduce a small right crop of 84 samples (5.3 ms). This means each output decision depends on 5.3 ms of “future” audio. In practice, this is negligible and the network can be considered near-causal with an effective latency of 9.5 ms.

Design trade-off: VAD_H_C24_L10 invests 11.5× more compute to achieve wider channel widths (32 vs 8), finer temporal resolution (250 Hz vs 125 Hz), and a deeper decoder, at the cost of a slightly higher latency (9.5 vs 8.0 ms) and a small non-causal component (5.3 ms right crop).
